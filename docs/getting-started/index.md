# Getting Started

This section takes you from an empty directory to a running Go application.

Start here to create a project, run it locally, and learn where routes, services, configuration, and dependency wiring belong.

## Recommended Path

1. [Quickstart](/getting-started/quickstart) creates, builds, runs, and verifies a local app.
2. [Project Structure](/getting-started/project-structure) explains the directory layout and ownership boundaries.
3. [Configuration](/getting-started/configuration) explains `.goforj.yml`, environment files, and driver selection.
4. [JSON API Route](/scenarios/json-api-route) walks through a first route, controller, service, Wire provider, and test.
5. [Runnable Scenarios](/scenarios/) continue through cache, storage, events, jobs, schedules, and observability.
6. [Starter Kit Guide](/getting-started/starter-kits) explains the optional frontend code created with a project.

## Next Practical Steps

- [Commands](/applications/commands) explains app commands and where custom commands belong.
